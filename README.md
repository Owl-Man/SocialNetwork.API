Охвачен определенный функционал из работы социальных сетей. CRUD операции с Users и Posts.
Запросы на получение пользователя оптимизированы засчет кэширования в Redis.
Приложение, база данных на PostgreSQL и Redis поднимаются в отдельных контейнерах с помощью docker-compose.


```Bash
docker compose up -d
```
